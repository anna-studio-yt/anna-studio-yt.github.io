Политика конфиденциальности / Privacy Policy

Обновлено / Updated: 2026-09-25

Русский

  • Anna Studio запрашивает доступ к YouTube-аккаунту владельца только для загрузки видео (youtube.upload) и чтения названия собственного канала (youtube.readonly).
  • Токен доступа хранится только локально на компьютере владельца. Он не передаётся третьим лицам и не хранится на серверах.
  • Инструмент не собирает, не продаёт и не передаёт персональные данные, не использует рекламу и аналитику.
  • Использование данных, полученных из API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.
  • Отозвать доступ можно в любой момент: myaccount.google.com/permissions.

English

  • Anna Studio requests access to the owner's YouTube account only to upload videos (youtube.upload) and to read its own channel name (youtube.readonly).
  • The access token is stored only locally on the owner's computer. It is never shared with third parties or stored on any server.
  • The tool does not collect, sell or share personal data, and uses no advertising or analytics.
  • Anna Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Access can be revoked at any time at myaccount.google.com/permissions.

Anna Studio uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
